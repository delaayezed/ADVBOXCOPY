Essa extenção faz algo muito simples, ela permite copiar as informações do cliente com mais facilidade no ADVBOX. Permite que você copie o o nome e número manualmete, mas também adiciona botões de copiar. 
A Instalação é simples: Gerir extensões do google
Habilitar o modo de programador/desenvolvedor
Carregar extenção expandida
Selecionar a pasta.
Após, é só atualizar o advbox.
